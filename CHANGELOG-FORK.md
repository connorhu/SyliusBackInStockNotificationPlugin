# Fork changelog

This file tracks the rounds of the pre-order work done in this fork of
`webgriffe/SyliusBackInStockNotificationPlugin` (see `docs/preorder-design.md`). One line per round.

- Round 1: PostgreSQL-safe migrations (platform branch in both existing migrations), PostgreSQL 17 CI job, unit-test suite (`phpunit.unit.xml.dist`), design document.
- Round 2: subscriptions get a `product` relation, a configurable `product`/`variant` target (`TargetResolver`), a lifecycle `status` (waiting/notified/fulfilled/cancelled, replaces `notify`), canonical e-mail and name, hold/dismiss fields; migration `Version20261030100000` (PostgreSQL + MySQL), UPGRADE-6.0.md.
- Round 3: pre-orderability: `Preorderability` enum, `PreorderabilityResolver` (product, taxon ancestry, channel default), host-entity traits/interfaces for product, taxon and channel settings, admin form fields via twig hooks, product-page block gated; migration `Version20261030110000` (PostgreSQL + MySQL).
- Round 4: guest pre-order with a name field, account linking (a guest e-mail of a customer with a shop user attaches the pre-order to that customer), confirmation mail with the manage link or the account link, and the signed 24-hour manage page (delete, delete all, 10-minute undo, rate-limited new-link request); upstream's GET delete-by-hash route is removed; adds `symfony/rate-limiter`.
- Round 5: pre-order rate limit (one new pre-order per e-mail/customer per channel interval, checked in the database; sliding window of 10 per hour per client IP via the `webgriffe_bisn_preorder_ip` limiter; a duplicate never consumes a token) with a friendly, interval-aware message that keeps the form data, and a honeypot that answers a bot with the guest success state without storing or mailing.
- Round 6: restock processing rewrites the `alert` command around `RestockProcessor` (expire lapsed holds with a `hold_expired` mail, move notified pre-orders of a sold-out target back to waiting, allocate free units = sellable units minus active holds: `fastest` notifies everyone, `queue` holds one unit per pre-order for the channel's hold hours, in `createdAt` order), `SellableUnits` (Sylius' plain availability, enabled, in channel, priced), state flushed per target before its mails, `LockableTrait` against overlapping runs (adds `symfony/lock`), cron every 5 minutes.
